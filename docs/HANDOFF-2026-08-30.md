## 1. The drift class — what it was, and why it matters more than the six entries

`sample.mjs` excludes archived repos. So when a curated `TAXONOMY` repo gets
archived upstream, it stops resolving, and every generator does this:

```python
present = [n for n in sel_names if n in by_name]   # all 26 reports
```

The entry vanishes from the generated tables while the **hand-written prose
around it keeps discussing the tool as a live option**. The generator noticed and
said so on stdout. `build_index.py` discarded stdout. Nobody saw it for five
weeks.

What drifted, and when it left the dataset:

| Repo | Last present | Cause |
|---|---|---|
| `browserbase/mcp-server-browserbase` | 2026-07-20 | archived |
| `abhi1693/openclaw-mission-control` | 2026-07-27 | archived |
| `FlowiseAI/Flowise` | 2026-08-11 | archived |
| `evrendom/rudel` | 2026-08-11 | renamed → `opalinehq/cli` |
| `airweave-ai/airweave` | 2026-08-28 | archived |
| `matrixorigin/Memoria` | — | case-only rename → `matrixorigin/memoria` |

Two of those had real consequences worth knowing about:

- **`agent-orchestration` was recommending an archived project.** Flowise sat in
  "highest-health picks (92)" — a frozen score for a repo that had left the
  dataset months earlier.
- **`agent-memory` had silently deleted its own headline finding.** Its
  primitives matrix filtered rows on `n in by_name`, which dropped airweave's
  row — while the prose around it still built the report's central claim ("the
  one exception in the entire set") on that row. `PRIMITIVE_EVIDENCE` is read
  from each tool's *source code*, not from live metrics, so archiving upstream
  does not invalidate it. Retired tools stay in that matrix now, tagged
  `(archived)`.

### The convention now

Archived-upstream entries move from `TAXONOMY` into a `RETIRED` dict:

```python
RETIRED = {
    "owner/repo": (category, "why it left, plus the original description", "YYYY-MM-DD"),
}
```

They leave the scored tables — so star totals and health averages stay honest —
but render in a *Retired from the scored set* section with frozen metrics and a
reason, instead of disappearing. If one comes back (unarchived, or re-pointed
after a rename), the row flags itself for re-promotion.

**A case-only rename is invisible to the eye and fatal to a dict lookup.** The
dataset keys on the exact `full_name`. `matrixorigin/Memoria` matched nothing for
an unknown length of time. I swept all 26 reports for this class; it was the only
one. Re-run that sweep if a repo ever "disappears" for no reason:

```python
lower = {n.lower(): n for n in names}
[k for k in taxonomy_keys if k not in names and k.lower() in lower]
```

## 2. Drift runs both ways — the 45

The larger find. A gap table's entire claim is *"these repos are missing from
your stars."* Once one gets starred, the report is asserting a falsehood.
`agentic_terminals.py` and `jetson_inference.py` both already checked for this
and printed a warning — into `/dev/null`.

45 repos had been starred out from under their own gap tables. This was the
08-28 handoff's open §6, and it turned out to be machine-detectable rather than
a research task.

- **`agentic-terminals`: 38 of 45 promoted.** Merged onto the richer 7-layer
  vocabulary the gap table already used (`Agent-aware terminal`, `Emulator`,
  `Multiplexer / session`, `Parallel-agent orchestration`, `Remote & web
  sessions`, `Windows & shells`, `Shell & history`) plus the two original
  categories that had no layer equivalent. **52 curated, 7 still absent.**
- **`jetson-inference-engines`: 7 promoted**, with a new *Compiler & substrate*
  category for `ggml` / `tvm` / `onnxruntime`. **24 curated, 4 still absent.**

### The terminals report's thesis had inverted

It was written around "the stars cover coding agents exhaustively and the
terminal underneath them barely at all" — 14 held against 45 catalogued gaps.
That is now 52 held against 7. The bullet asserting **"You have zero agent-aware
terminals"** was flatly false: `cmux`, `warp` and `waveterm` are all starred.

It is now computed from `cats["Agent-aware terminal"]` rather than asserted, so
it cannot go stale the same way again. **Prefer this shape** — the hand-written
superlative is the thing that rots.
