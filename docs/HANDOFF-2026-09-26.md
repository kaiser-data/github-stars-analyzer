`reports/`, `public/`, `data/classified.json` and `src/data/sample-all.json`.

followed by a rebuild with `build_index.py`. Star deltas now measure against the
09-21 snapshot.

is in a generated file, take whichever side has the newer data, then rebuild.
Never merge generated markdown by hand.

How `--model` runs:

- It runs `uv run --python 3.12 --with gliclass` as a child process. No Python
  dependencies are added to the repo.
- The first run downloads about 600 MB (`knowledgator/gliclass-modern-base-v3.0`).
- Without uv, or on any error, it falls back to keyword-only and says so.
- It uses about 1.3 GB of RAM, and a 47-candidate pass takes about 26 s on the M2.

Tests: `npm run test:discover` 89/89 and `npm run test:graph` 17/17.

## 3. What the GLiClass evaluation found

`docs/notes/2026-09-25-gliclass-relevance-pilot.md` has all the tables. In short:

1. **Offline, on repos that belong to reports:** the combined score matched or beat
   keyword on rag-tooling, agentic-terminals and voice-agents (AUROC 0.99, 0.94 and
   0.90). Keyword relevance takes only a few distinct values, so at a nominal 10% FPR
   its real FPR was 15–26%.
2. **Live, with a known-gap proxy:** this looked negative (AUROC 0.27–0.34), but the
   proxy was misleading. Do not reuse it.
3. **Live, on 47 hand-labelled search hits:** combined scored 0.76 against keyword's
   0.66. Descriptive labels did not help, so the bare category names stay.
   **The labels in `data/labels-agentic-terminals.txt` are Claude's, not the
   owner's**, and with only 13 negatives the standard error is about ±0.08.

**`--model` stays opt-in until the owner has reviewed the labels and a second
report agrees.**

Scratch code, not committed: `export.mjs`, `score.py`, `dump.py`, `combine.py` and
`live_eval.mjs`, in the session scratchpad. `live_eval.mjs` is worth recreating if the
evaluation is rerun: it resolves the labelled names, runs `modelRelevance` for each set
of labels, and prints AUROC and the number of off-topic repos in the top half.

## 4. Lessons from this session

- **A proxy label is not a label.** "Known-gap vs new" (live test 1) reversed the
  conclusion that real labels gave. Use hand labels as the evidence.
- **Long local runs need `caffeinate -i`.** The Mac went into deep sleep on battery,
  and the model process hung for 3 hours on a dead Hugging Face request. That is why
  the timeout and offline mode now exist.
- **`--no-search` overwrites `reports/<slug>.candidates.*`** with a gaps-only list. The
  files are gitignored, but rerun discovery with search before building a labelling
  sheet from them.
