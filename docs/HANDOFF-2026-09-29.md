## 3. Lessons

- **Check the sibling study before calling something blocked.** The 09-26 handoff said hosted Jev was
  blocked, while `jev-studies` had already run it through OpenRouter. Read `../jev-studies/HANDOFF.md` and
  `RESULTS.md` before touching Jev claims here.
- **`RESULTS.md` can be ahead of its own handoff.** Test I existed there and was not mentioned in
  `jev-studies/HANDOFF.md`.
- **The auto-mode classifier blocks rebases of `main`.** The route that worked was to merge onto a branch,
  then have the owner run `git merge --ff-only` and push.
