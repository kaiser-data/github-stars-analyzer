## 3. Lessons

- **Run a rename diff after every refresh.** Compare the old and new `full_name` sets from
  `data/classified.json`, then resolve each removed name with `gh api repos/<name>`. This session found 3
  renames and 3 archivals that reports were relying on. Without the diff they show up as `WARNING missing:`
  at best, and as silent loss at worst.
- **A hand-applied shortlist filter hides real candidates.** `SWE-agent/mini-swe-agent` and
  `UKGovernmentBEIS/inspect_ai` *were* in the candidate JSON (harness-engineering, llm-evaluation), but they
  fell below my `health ≥ 55, relevance ≥ 0.6` cut. The open "`--extra` names cut by `--limit`" item was
  **not** the cause.
- **`npm run refresh` takes more than 10 minutes** for about 2,300 repos. Run it in the background.
