Method

No model guesses in the answer path.

Scores are deterministic. Recommendations are written by a person and dated. An agent asking Picker gets data, not generated text.

Collect

Weekly pull from the GitHub API: stars, commits and authors over 90 days, releases, issues. Snapshotted, so trends are real.

Score

Lifecycle stage (Rising to Abandoned), health 0–100, bus factor and top-author share. Same input, same score.

Curate

Per domain: taxonomy, strengths, weaknesses, and a ranked pick for each job. Written by hand and checked against what we found missing.

Serve

Precomputed JSON behind the Atlas, the Almanac and the Picker MCP. Every answer cites its report and snapshot date.

Trust policy

Recommendations are not for sale.

No paid placement

No maintainer, vendor or sponsor can buy a pick, a ranking or a removal. Ever.

Dated and cited

Every pick names the report and snapshot it comes from, so anyone can check why.

Own repos labelled

When a project by the curator appears in a report, it carries a label.

Disputes in public

Think a pick is wrong? Open an issue. Corrections are logged with the date.
