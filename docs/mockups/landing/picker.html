Where it fits

Three questions an agent asks. Picker answers the one nobody else does.

Context7, DeepWiki, GitMCP“How do I use library X?”

Current docs and code examples for a library you already chose.

Socket, Snyk, OSV“Is package X dangerous?”

Malware, vulnerabilities and supply-chain risk.

Astrolab Picker“Which library for this job, and which to avoid?”

Curated picks per job, with maintenance risk on top. Use it before the other two.

Three tools

Small surface, answers from data.

No language model sits behind these calls. Each answer is precomputed from a curated report and the latest weekly snapshot.

pick(job, constraints?)

Top three for the job with why each fits and where it falls short, plus repos to avoid and why. Constraints: language, licence, self-hosted, minimum health.

check(owner/repo)

Lifecycle stage, health score, bus factor, days since last push. If a curated alternative exists, it names it.

landscape(topic)

The report's categories, its decision table, and how many repos it covers. For when the agent needs to explain a choice to you.

Benchmark

Does it change what agents pick?

We give coding agents 20 real jobs from the launch domains, three runs each, under three setups: no tool, Context7 only, Context7 plus Picker. Each choice is scored as one of:

  1. picked a Declining or Abandoned repo
  2. picked a package that doesn't exist
  3. picked the most popular option where a better fit existed
  4. picked well

Prompts, transcripts and scoring are published with the results.
