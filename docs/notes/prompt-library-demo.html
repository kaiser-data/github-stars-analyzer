02

The part that is actually new

These prompts decay loudly. The stack is resolved against your dataset at generation time, not typed into prose. When a tool gets archived upstream it leaves the dataset, drops out of the table, and the build prints a warning while the prompt itself renders a banner saying which tool went missing.

A hand-written prompt library cannot do that. It keeps recommending a dead tool silently, forever, until a human happens to notice.

There is an honest limit worth stating on the same page. Look at the first row of the table above: fogleman/sdf, health 4, last pushed August 2024. It is not archived, so nothing warns about it — it is simply finished. A small SDF library whose maths does not change looks identical to an abandoned one, and no metric here separates them. That is why the health column is printed inline rather than hidden: the page shows you the number and trusts you to read it.

04

Using it

Prompts live beside the reports and regenerate with them. One command rebuilds every report and every prompt against the current dataset — no API calls, fully reproducible.

# rebuild everything: 27 reports + 3 prompts python3 scripts/reports/build_index.py # then open the app and use the Prompts tab npm run dev

Each parent report grows a Build something with this stack section linking to the prompts made from it, so the path from a landscape you were reading to a thing you can build is one click, in the direction you were already going.

Status. Feature complete; fixes for both merge blockers have landed and are in final review. A whole-branch review had returned two — a prompt whose tool choice contradicted its own parent report, and a failure path that could leave the published copies of reports out of sync. The stacks shown above are the corrected ones.

Honest caveat. Nothing here can check that a stack is the right answer, only that its repos exist. One of the three prompts shipped a tool its own report explicitly rejected, and every automated check passed. Choosing the stack stays an editorial judgement.
