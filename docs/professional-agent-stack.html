Read this first — your class is A

The M2 you are on is 8 GB and currently running ~6.3 GB of swap. Everything marked A is chosen to coexist with 3 concurrent agents — not 4. Budget by the pane, not the binary: measured on this machine (M2, Ghostty 1.3.1, herdr 0.8.2), one Claude Code pane is ~205 MB bare but ~450 MB with MCP servers loaded, because the sidecars it spawns (chrome-devtools-mcp 83 MB, its npm exec wrapper 105 MB, claude-mem 29 MB, launcher 12 MB) outweigh the 205–230 MB agent binary itself. Three such panes is ~1.35 GB; four is ~1.8 GB on a box already 5 GB into swap. Class B and above are listed so the stack still makes sense after a hardware change — and so you can push the heavy half to a server instead.

Measured, not cited — footprint -p against a live herdr agent pane, 2026-09-07. The earlier "100–320 MB each" counted only the agent process and missed every sidecar in the same pane.

The single highest-leverage line in this document is not a tool: one git worktree per agent. It costs nothing, and it is what stops parallel agents from corrupting each other's edits.
